# Windows 智能安全卫士 (PC Security Center) 1.2.0

本软件按"现状"提供，不含任何形式的担保。安装即表示您理解并同意以下条款：

一、本软件的病毒检测能力依赖 Microsoft Defender 官方引擎与病毒库，不能保证检测出所有威胁。
二、SmartRisk 引擎的检出结论为"可疑/提示"级别并附依据说明，需人工判断，不构成病毒判定。
三、安全评分仅反映本软件所定义检查项的量化结果，不代表系统绝对安全。
四、本软件默认以最小权限运行，不收集、不上传任何用户数据；不静默关闭 Defender 或防火墙，不安装驱动或内核组件。
五、涉及系统级修改的操作（清理、启动项禁用、计划任务与服务启停等）均需您逐次确认，并记录日志、尽可能可回滚。
