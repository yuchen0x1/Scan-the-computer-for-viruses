## 1.2.0 (2026-11-10)

正确性修复版本。四项 P0 缺陷均为「界面承诺的行为与实际行为不一致」，建议所有用户升级。

### 安全与正确性修复（P0）
- **提权执行修好**：`UseShellExecute=false` 时 `Verb=RunAs` 会被 .NET 静默忽略，此前所有「提权操作」实际以标准权限运行且界面仍告知用户已提权。现改为 ShellExecute + UAC 启动，参数经 `-EncodedCommand` 传入，子进程把结果写入一次性 JSON 文件回传；子进程必须确认自身为管理员，否则按失败处理。用户取消 UAC（Win32 1223）单独提示「已取消提权」。SFC / DISM / chkdsk / 还原点 / 计划任务 / 服务启停全部受益。
- **全盘扫描不再重复扫描子树**：旧实现把祖先目录与后代目录同时投递给 Defender 递归扫描，实测同一棵 21 文件目录树被检查 69 次（3.29 倍）。现按反链分区，只投递互不包含的扫描单元；同时补上「根目录既有子目录又有直系文件」时被漏扫的直系文件，文件单元按 1 个文件计数。
- **威胁处理改为按 ThreatID 定点**：旧实现调用不带 `-ThreatID` 的 `Remove-MpThreat`，点一条记录会清除**全部**活动威胁。现强制要求合法 ThreatID，非法值在进入脚本前拒绝；无 ThreatID 的遗漏记录明确提示到 Windows 安全中心处理，不再退化成全局清除。
- **扫描记录可关联**：每次扫描生成唯一 RunId，贯穿 `ScanProgress`、`ScanContext`、威胁记录与扫描记录。Defender 最近 30 天的历史检出不再被错误归属到当前扫描，只补充本次时间窗口内的记录。

### 修复
- **旧版隔离密钥迁移失败**：v1.0 遗留的 32 字节明文 `vault.key` 带 Hidden 属性时，`File.WriteAllBytes` 覆盖会抛「访问被拒绝」，导致「病毒查杀」页无法打开。现改为同目录临时文件 + 原子替换，DPAPI 往返校验通过后才删除旧密钥备份；失败自动回滚，绝不生成新密钥导致既有隔离数据丢失。
- **关于对话框版本号**：改为读取程序集版本，不再硬编码 v1.0.0。

### 工程化
- App 目标框架改为 `net10.0-windows10.0.19041.0`，LiveCharts 升至 2.0.5，消除 NU1701 依赖回退警告；WFO0003 带注释抑制（保留 WPF PerMonitorV2 DPI manifest）。
- 新增 P0 回归测试：提权启动配置与参数转义、分区反链与逐文件覆盖、RunId 贯穿、非法 ThreatID 拒绝、隐藏密钥迁移与旧隔离格式恢复。全量测试 101 项通过。

### 兼容性说明（重要）
- 由于目标框架带有最低 OS 版本，本版本起要求 **Windows 10 2004 (build 19041) 及以上**；Windows 10 1809/1909 无法安装或运行。Windows 11 不受影响。
- 隔离区密钥升级后仍使用同一原始 AES 密钥，v1.0 旧格式隔离文件可正常恢复。

## 1.1.0 (2026-11-09)

安全加固与工程化升级版本。

### 安全加固（重要，建议所有用户升级）
- 自动更新链全链路校验：下载源限定 GitHub 官方主机、资源文件名净化（防路径穿越）、字节数核对、SHA256 与 Release 附带 SHA256SUMS 比对、Authenticode 签名验证（含证书吊销状态检查），安装前二次比对哈希防替换；无签名且无校验和的安装包一律拒绝执行
- 隔离区加密重做：AES-256-CBC + HMAC-SHA256 认证（encrypt-then-MAC），密文被篡改直接拒绝恢复；主密钥改用 DPAPI（CurrentUser）保护存盘，杜绝密钥文件泄露即可解密；v1.0.0 的旧隔离数据仍可正常恢复（密钥与旧格式自动迁移）
- 隔离区健壮性：流式加解密（大文件不再占满内存）、索引原子写 + 备份（损坏保留现场不覆写）、哈希与加密单次读取（消除 TOCTOU）、原文件删除失败自动回滚

### 修复
- 安全评分：全部检查项不可读时如实显示「未知/评分不可用」，不再误判为危险 0 分；移除未实现的威胁扣分占位代码
- SmartRisk 引擎：双扩展名伪装检测改为大小写不敏感（`invoice.PDF.exe` 不再漏检）；超大脚本改为检查文件前段而非整体跳过
- 提权执行：修复子进程输出缓冲区占满导致的死锁；创建还原点后恢复原 SystemRestorePointCreationFrequency 设置
- 签名验证：启用证书整链吊销检查（仅用本地缓存，不联网卡顿）；吊销证书不再误报有效
- 实时防护：启动文件夹事件加去抖、定时轮询加重入保护，事件风暴下资源占用可控
- 路径安全：系统关键目录改为动态识别（Windows 装在非 C 盘同样受保护），并解析 junction/符号链接防止绕过
- 修复多处同步阻塞调用，避免界面冻结

### 工程化
- 新增 root 级 MIT LICENSE、GitHub Actions CI（构建 + 81 项测试）
- 版本号单源化（Directory.Build.props），发布脚本自动注入安装包版本并生成 SHA256SUMS.txt
- 本次共 81 个单元/集成/安全测试全部通过（新增隔离区旧格式兼容/HMAC 篡改拒绝、更新链文件名净化/校验和解析、评分边界、双扩展名大小写等 15 项）


## 1.0.0 (2026-11-07)

首个公开版本。

### 核心能力
- 安全驾驶舱：真实数据综合评分（规则公开）、状态卡、性能卡片、事件流
- 病毒查杀：快速/全盘/自定义扫描，Defender 官方引擎 + SmartRisk 风险规则引擎，暂停/继续/取消，真实进度
- 威胁处理：隔离/删除/忽略，AES-256 加密隔离区 + SHA256 双重完整性校验
- 实时防护：启动目录事件驱动监控、Run 键/进程/Defender 状态低频轮询，风险提示全部附依据
- 网络安全：TCP 连接进程关联与签名检查、防火墙配置、代理/Hosts/DNS 检查、实时流量
- 系统安全：15+ 项真实检查，权限不足/不支持如实标注
- 性能监控：CPU/GPU/内存/磁盘/网络真实采集（不虚构数据），LiveCharts2 曲线
- 系统维护：先扫描后清理（白名单目录），SFC/DISM/chkdsk 只读检查，还原点管理
- 启动项/软件管理：只读枚举 + 风险标注，禁用可恢复，官方卸载入口
- 文件分析：哈希/PE/签名/熵全本地分析，EICAR 引擎自检
- 安全报告：HTML / PDF 导出，如实标注覆盖范围与限制

### 安全设计
- 默认最小权限；提权操作白名单脚本模板 + 环境变量传参（无命令注入面）
- 所有删除/隔离操作路径校验（绝对路径 + 系统关键目录保护 + 路径遍历拒绝）
- 全操作日志（Serilog 滚动文件），数据库记录可追溯

### 测试
- 46 个单元/集成/安全测试（评分、路径安全、PE 解析、隔离区篡改防护、PowerShell 注入防护、Defender 集成等）
- E2E 验证：EICAR 标准样本 → Defender 真实检出记录
- Windows 11 x64 快速扫描验收：153,558 个文件；3,970 条 SmartRisk 可疑/提示记录（不是 3,970 个确认病毒）；Defender 历史记录单独统计

### 安装包修正（1.0.0 r1）
- 修复许可协议页中文乱码：`LICENSE.rtf` 原先未声明代码页且以原始 UTF-8 字节写入中文字符，
  Inno 的 RichEdit 按 GBK 解码导致乱码。现改为标准做法：头部声明 `\ansicpg936`，
  所有非 ASCII 字符写成 `\'xx` 十六进制转义。生成脚本见 `installer/tools/Make-LicenseRtf.ps1`，
  文本源为 `installer/LicenseText.md`。
- 修复安装向导按钮与页面标题回退英文：原中文语言文件误用 Inno Setup 5 的键名
  （`BtnNext`/`BtnBack` 等），Inno Setup 6 已改名为 `ButtonNext`/`ButtonBack` 等，导致
  全部消息静默回退英文。现按 `Default.isl` 的权威键名补齐全部消息键，编译告警由 673 条降为 0。
- 修复许可协议说明文字重复显示：`LicenseLabel` 与 `LicenseLabel3` 会同时渲染，已将后者置空。
- 安装前信息页改用纯文本 `installer/安装前信息.txt`：原先引用 Markdown 文件，
  `#`、`**`、`-` 等标记会被原样显示。

- 新增官方安装包：基于 Inno Setup 6 制作的标准 Windows 安装程序（Setup-1.0.0.exe），
  支持安装目录选择、桌面快捷方式、卸载程序与「控制面板-程序和功能」条目，安装过程不关闭系统防护、

- 更新通道首个可用版本即本次发布的 v1.0.0（安装包 + 便携版），后续版本可由自动更新直接从官方发布页拉取。
