# Windows 智能安全卫士 · 使用说明

版本：1.0.0　|　平台：Windows 10 / 11（x64）

## 一、安装与启动

- **安装版**：运行 `Windows智能安全卫士-Setup-1.0.0.exe`，按向导完成安装。安装程序不会关闭系统防护、不会设置任何隐蔽开机自启。
- **绿色便携版**：解压 `Windows智能安全卫士-1.0.0-portable.zip` 到任意目录，运行 `PcSecurityCenter.App.exe`。便携包为自包含部署，无需额外安装 .NET 运行时。
- 默认以**标准权限**运行（推荐）。以下功能需要管理员权限，执行时会弹出 UAC 确认并由你逐次授权：
  - 系统安全检查中的 TPM / BitLocker / Secure Boot / SMBv1 详细读取
  - SFC / DISM / chkdsk 磁盘检查（默认只读检查，不修复）
  - 创建系统还原点、计划任务/服务的启用与禁用

## 二、日常使用建议

1. **每周一次「一键全面体检」**（安全驾驶舱页）：约 1-2 分钟，产出真实评分与修复建议。
2. **每 1-2 周一次「快速扫描」**（病毒查杀页）：Defender 原生快速扫描 + 启动目录/临时目录风险检查。
3. **每月或安装新软件后**：可执行「全盘扫描」（耗时较长，支持暂停/继续/取消）。
4. **发现风险时**：优先选择「隔离」（可恢复）；确认无用再「彻底删除」。「忽略」不会影响 Defender 对该文件的实时检测。
5. **隔离区**：加密存储于 `%APPDATA%\PcSecurityCenter\Quarantine`，可随时恢复或彻底删除。

## 三、权限不足说明

部分系统级检查（TPM/BitLocker/Secure Boot 等）在标准权限下会显示「权限不足」。这是**如实告知**而非功能缺失：本工具不会默认将读不到的项目显示为"安全"。如需完整检查，可右键 `PcSecurityCenter.App.exe` →「以管理员身份运行」。

## 四、隐私声明

- 所有分析、扫描、检查均在**本机完成**，本工具**不上传任何文件内容、文件哈希或使用数据**。
- 「哈希信誉查询」为可选功能，默认关闭；需你在设置中心显式启用并配置自己的 API Key 后才会联网（且仅发送文件哈希，不发送文件内容）。
- 应用数据（数据库/日志/报告）全部保存在本机 `%APPDATA%\PcSecurityCenter\`。

## 五、常见问题

**Q：评分是怎么算的？**
A：每项检查带权重：通过=100%、注意=60%、风险=0%；读不到的项目不计入分母。规则完全公开，见 README。

**Q：全盘扫描为什么比杀毒软件慢？**
A：本工具将文件逐目录交付 Defender 引擎扫描以获得真实的进度/暂停/恢复控制，牺牲了部分速度换取透明可控。

**Q：GPU 利用率显示"不可用"？**
A：本机没有 GPU 利用率性能计数器且无 nvidia-smi 时，工具如实显示不可用，不会生成虚构数据。温度同理。

**Q：误报了怎么办？**
A：SmartRisk 的检出均为「可疑/提示」级别并附依据说明，可在威胁列表选择「忽略」；Defender 检出的威胁请在 Windows 安全中心反馈误报。

## 六、卸载

- 安装版：设置 → 应用 → 找到「Windows 智能安全卫士」→ 卸载（或控制面板）。
- 绿色版：直接删除目录。
- 卸载后 `%APPDATA%\PcSecurityCenter\` 中的用户数据（报告/日志/隔离文件）会保留，如不再需要可手动删除。
