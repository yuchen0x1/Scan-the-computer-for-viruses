# 发布历史

## v1.2.4 — 2026-11-13

- 扫描根路径去重，文件计数不再累加两个引擎；同一文件的规则提示与 Defender 检出分别保留。
- 扫描结束仍显示 Defender 不可用、失败或提前退出等覆盖限制；扫描历史与 HTML/PDF 导出保留真实范围和限制。
- 修复再次扫描后风险不显示、结果保存未完成就允许下一次扫描的问题；取消/失败不再更新时间为成功扫描。
- 威胁列表支持名称、路径、引擎与依据搜索及“仅确认威胁”筛选，状态标签使用中文。
- Defender 单条处理明确引导到 Windows 安全中心，不再调用不存在的 `-ThreatID` 参数；忽略仅作用于当前记录，不再承诺不存在的永久白名单。
- 配置使用串行原子替换保存；隔离、恢复、删除串行执行，减少并发索引丢失风险；恢复不会覆盖同名恢复文件。
- 修正扫描及其他页面忙碌状态按钮绑定，提升亮色主按钮文字对比度。

- 便携版不再附带开发调试符号。

本地安全回归 113 项通过，WPF 扫描页与自包含构建通过。安装包未签名，Windows 可能显示 SmartScreen 提示；尚未完成真实跨版本更新验收。验证范围与限制见 [本轮升级报告](../evolution-2026-11-13.md)。

## v1.2.3 — 2026-11-12

### 用户可见变化

- 在线更新不再只依赖容易触发匿名限流的 GitHub REST API。
- 更新中心支持静态清单和 Releases Atom feed，离线缓存会明确标注且不会直接下载。
- 更新包下载失败最多自动重试 3 次，安装前校验文件大小、SHA256 和数字签名状态。
- beta/rc 预发布版本不会被稳定通道误识别为正式更新。
- 发布版本标签会自动触发 Windows 构建、测试、安装包/便携版打包、SHA256 和 `update.json` 生成。

### 验证状态

- 自动化测试：107/107 通过
- 本机安装与启动烟测：通过
- 代码签名证书：BLOCKED，当前安装包未签名
