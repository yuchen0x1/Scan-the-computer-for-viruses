# 发布历史

按新到旧列出所有正式版本，日期采用北京时间，以 GitHub Release 公开时间为准。内容依据版本间源码差异和原始发行记录整理；后续确认的限制会在旧版本下更正。

这是更新日志的维护源。`installer/更新日志.md` 由 `tools/Sync-ReleaseNotes.ps1` 生成，供安装包和离线更新中心使用。已发布安装包内的历史文档不会随仓库文档编辑而改变。

## v1.2.4 — 2026-11-13

扫描可靠性、结果归档和威胁列表体验升级。

### 扫描与结果

- 合并重复或相互包含的扫描根路径，修复两个引擎叠加文件数的问题。界面显示本工具的已枚举文件数，不将其当作 Defender 内部实际检测量。
- 同一文件的 SmartRisk 规则提示与 Defender 确认威胁分别保留，修复并发去重可能遗漏告警的问题。
- 修复连续扫描时新结果被旧去重记录隐藏、历史统计与威胁记录不一致的问题；等待结果保存后再允许下一次扫描和威胁处理。
- Defender 不可用、扫描失败或目录扫描提前结束时，覆盖限制持续显示，并写入扫描历史及 HTML/PDF 报告；空扫描范围明确报错。
- 修复目录扫描消费者提前退出后可能无法结束的问题；估算任务在扫描结束前收尾，避免影响下一次扫描。
- 取消、失败或覆盖受限的扫描不再更新为最近一次成功扫描。

### 威胁处理与界面

- 新增名称、路径、引擎与依据搜索、“仅确认威胁”筛选和显示数量。
- 风险级别、检测类型与处理状态使用中文标签；修复扫描及其他页面忙碌状态按钮绑定，改善亮色主按钮文字对比度。
- 更正旧版“按 ThreatID 定点处理 Defender 威胁”的说明：官方 `Remove-MpThreat` 不支持此参数。本工具拒绝该操作，引导到 Windows 安全中心的保护历史记录，并保留原活动记录。
- “忽略”仅标记当前检测记录，后续扫描仍会重新检查，不创建永久白名单或修改 Defender 排除项。

### 数据、发行与验证

- 配置保存采用串行写入与同目录原子替换，失败时保留旧配置并提示错误。
- 隔离、恢复、删除串行执行，减少索引并发丢失；恢复禁止覆盖同名目标，解密失败后清理临时明文。
- 便携版不再分发本项目 PDB；打包不再按进程名强制结束用户程序。发布页与更新清单使用本版本说明。
- GitHub CI 与发布工作流均成功，测试报告为 120/120 通过，构建 0 警告、0 错误。发布资产已下载核对，大小、SHA256 与清单一致，便携版不含 PDB，程序版本为 1.2.4。
- 安装包未签名。真实威胁处理、多 DPI 全页面验收和老客户端安装新版本的完整流程尚未完成，自动化测试不能替代这些验收。

## v1.2.3 — 2026-11-12

在线更新可靠性、扫描规则和设置持久化完善。

### 更新中心

- 优先读取静态 `update.json`，其次使用 Releases Atom feed，GitHub REST API 作为回退，减少匿名 API 限流造成的检测失败。
- 缓存结果标注来源与时间，不能直接触发下载；稳定通道过滤 beta/rc 等预发布版本。
- 下载失败最多重试 3 次，校验大小、清单 SHA256 或 `SHA256SUMS.txt`，并检查已有签名的有效性。
- 启动只检查版本，下载由用户触发，应用更新由用户确认。移除 60 秒自动重启倒计时，扫描中更新先提示中断影响。

### 扫描、防护与设置

- 排除路径接入 SmartRisk，支持换行或分号分隔，不修改 Defender 排除设置。
- 低信号脚本提示按内容依据分级，减少开发目录噪音，保留高风险内容规则。
- 实时防护按 PID 与启动时间跟踪进程，避免 PID 复用误报；增加事件去重，降低常见构建工具临时进程的提示级别。
- 配置保存失败明确提示，日志保留天数接入实际日志策略。
- 开启病毒库自动更新后，启动时对超过 24 小时未更新的病毒库尝试调用 Defender 官方接口。
- 移除尚未接入的哈希信誉查询开关与 API Key 输入，文件分析继续本地完成。

### 发行与限制

- 新增标签触发的 GitHub Actions 发布流程，生成安装包、便携版、校验文件与更新清单。
- 当时发布记录记载 107 项测试通过、构建 0 警告、0 错误；本次整理未重跑旧标签测试。
- 安装包未签名；多引擎计数、重复扫描显示和 Defender 单条处理限制在 v1.2.4 进一步修正。

## v1.2.0 — 2026-11-10

提权、扫描范围、历史关联与隔离密钥迁移修复。

### 安全与正确性

- 提权改用 ShellExecute 与 UAC，子进程验证管理员权限，通过一次性结果文件回传；取消 UAC 时单独提示。用于 SFC、DISM、chkdsk、还原点及受控任务/服务操作。
- 全盘扫描按互不包含的单元投递，避免祖先与后代目录重复递归；修复根目录同时包含子目录和直系文件时漏扫文件的问题。
- 生成统一 RunId，贯穿进度、上下文、威胁和历史；按时间窗口过滤 Defender 历史检出，减少错误归因。
- 旧隔离密钥带 Hidden 属性时改用临时文件加原子替换迁移到 DPAPI；验证原密钥后再完成迁移，保留旧数据解密能力。
- 关于对话框改为读取程序集版本。

### 兼容性与更正

- 目标框架改为 `net10.0-windows10.0.19041.0`，最低系统要求提高到 Windows 10 2004（build 19041），Windows 10 1809/1909 不再支持。
- LiveCharts 升至 2.0.5，处理依赖回退告警，保留 WPF PerMonitorV2 DPI 声明。
- **更正原说明**：本版尝试通过 `Remove-MpThreat -ThreatID` 限定范围，但官方 cmdlet 不提供此参数，不能宣称已实现单条定点清除。v1.2.4 已拒绝该调用并引导到 Windows 安全中心。
- 当时记录为 101 项测试通过，未覆盖上述接口的真实单条处理。本次未重跑旧标签测试。

## v1.1.0 — 2026-11-09

更新包校验、隔离区防篡改与工程化升级。

### 安全增强

- 下载源限定 GitHub HTTPS 主机，净化文件名、核对大小与 SHA256；已有签名须通过验证，安装前再次核对哈希。无签名且无校验和的安装包拒绝执行。
- 隔离区使用 AES-256-CBC 与 HMAC-SHA256 认证，篡改时拒绝恢复；主密钥使用当前用户 DPAPI 保护，兼容旧隔离格式。
- 流式加解密减少大文件内存占用，索引原子写入并备份，原文件删除失败时回滚隔离操作。
- 动态识别系统关键路径，增加 junction/符号链接相关防护；签名检查启用本地缓存的证书链吊销验证。

### 修复与工程

- 全部检查项不可读时评分显示未知，避免误报为危险 0 分。
- 双扩展名规则大小写不敏感；超大脚本检查前段内容，不再整体跳过。
- 实时防护增加事件去抖、轮询重入保护，修复部分同步等待和输出缓冲问题。
- 创建还原点后恢复原频率设置；真正的 UAC 提权启动问题随后在 v1.2.0 修复。
- 增加 MIT LICENSE、CI、版本号单一来源与发布校验文件；修复脚本复制多份说明文件的参数格式。
- 当时记录为 81 项测试通过，未提供真实跨版本安装和签名发布的完整验收证据。SHA256 提供完整性比对，不等于独立发布者身份认证。

## v1.0.0 — 2026-11-08

首个公开发行版本，提供 Windows 自包含安装包与便携版。

### 核心能力

- 驾驶舱展示系统评分、防护状态、性能卡片和安全事件，检查项与评分规则公开。
- 接入 Microsoft Defender，结合本地 SmartRisk，提供快速、全盘和自定义扫描。SmartRisk 只报告有依据的可疑风险或提示，不将未知文件直接判为病毒。
- 提供隔离、删除、忽略与详情，隔离数据加密存储；HMAC 与 DPAPI 加固在 v1.1.0 引入。
- 提供启动目录/Run 键/进程/Defender 状态监控、TCP 连接与网络配置检查、系统安全检查和性能采集。
- 提供先扫描后清理的维护流程、系统检查工具、还原点、启动项与软件管理、本地哈希/PE/签名/熵分析、HTML/PDF 报告。
- 最小化与关闭窗口收进托盘，通过托盘菜单退出。

### 安装、更新与历史边界

- Inno Setup 安装包支持安装目录、快捷方式和卸载；便携版解压运行，二者内嵌 .NET 10 运行时。
- 更新中心整合检测和日志，在线读取 Release，离线回退本地更新日志。
- 当时会自动下载安装包并提供倒计时重启；从 v1.2.3 起改为用户明确触发下载和安装。
- 首批安装器文档记载修正许可页中文编码、中文按钮键名及安装前说明显示格式。
- Release 公开时间为北京时间 2026-11-08，早期文档的 2026-11-07 是开发日期。
- 早期 `v1.0.0` 标签早于安装/更新模块提交 `b9bf54e`；此处按首批 Release 描述和该提交补充发行能力，不宣称旧标签可完整复现安装包。
- 覆盖范围受 Defender、权限和硬件支持影响，不将历史单机扫描数或可疑提示数当作病毒检出率。
